Wipecord 1.3.4 gives target fields and activity logs more space with a slightly wider window. This release also includes the red all-server scope warning and clearer user messages introduced on main in 1.3.3.

The default panel is now 960 × 700 pixels, with a 350-pixel settings sidebar. Smaller screens still use the responsive layout and viewport limits. Selecting **all** highlights the Server ID field and button in red and explains the cleanup scope; the selected author and filters still apply, and selection never starts deletion.

Logs distinguish attempted deletion from confirmed removal and describe pauses in seconds. Cancellation and stopping are normal user actions, generic termination no longer implies success, and the final summary separates deleted, ignored, failed and already-gone messages. Message-picker instructions now explain the older/newer bounds.

## Install or update

Install the attached userscript with your userscript manager, or [install from main](https://raw.githubusercontent.com/rafelolv/Wipecord/main/wipecord.user.js). The main link follows future updates; this release's attachment is a fixed snapshot. No settings migration is required. Chromium requires version 111 or later; Firefox requires 142 or later.

For Chromium, extract its ZIP and load the folder through **Load unpacked** with Developer mode enabled. After replacing an existing local folder, click **Reload** for Wipecord in the extension manager and confirm version **1.3.4**. For Firefox, load its ZIP through `about:debugging#/runtime/this-firefox` for temporary local testing. See the [installation and update guide](https://github.com/rafelolv/Wipecord/blob/main/docs/EXTENSION.md).

Stop active operations before updating, keep only one Wipecord installation enabled, and reload all Discord tabs afterward. These ZIPs are unsigned local packages. This GitHub release does not publish to browser stores or provide a signed Firefox XPI; submit the Firefox ZIP to AMO separately for review/signing.

- Checked scope warnings and reset, preserved author/filters, no automatic run, inert hostile markup, defaults, startup/reload, duplicate prevention, confirmation/cancellation, cross-tab locking, history pagination, stopping, imports and anonymous reports using simulated responses only.

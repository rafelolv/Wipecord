## Install or update

- Install the attached userscript with your userscript manager, or [install from main](https://raw.githubusercontent.com/rafelolv/Wipecord/main/wipecord.user.js). The main link follows future updates; the attachment is a fixed snapshot. No settings migration is required.
- For Chromium, extract its ZIP and select the folder with **Load unpacked** in Developer mode. To update, replace the local folder and click **Reload** in the extension manager. Chromium 111 or later is required.
- For local Firefox testing, load the Firefox ZIP through `about:debugging#/runtime/this-firefox`. Firefox 142 or later is required. These ZIPs remain unsigned local packages; use the [Firefox Add-ons listing](https://addons.mozilla.org/en-US/firefox/addon/wipecord/) for permanent installation and Mozilla-managed updates.
- The release workflow submits the Firefox update after GitHub publication when its repository secrets are configured. Mozilla review/signing may still be pending. See [publication setup and status](https://github.com/rafelolv/Wipecord/blob/main/docs/FIREFOX-PUBLISHING.md) and [local installation instructions](https://github.com/rafelolv/Wipecord/blob/main/docs/EXTENSION.md).
- Stop active operations before updating, disable other deletion scripts, keep only one Wipecord installation enabled and reload all Discord tabs afterward.

## Validation

- Clean `npm ci` and `npm run check` passed lint, 42 mocked tests, metadata/license/syntax checks, byte-identical packaged engines and deterministic ZIP verification.
- Mozilla's local validator reported zero errors, warnings and notices. Local validation does not replace AMO review.
- Publication tests cover JWT signing, missing secrets, identity checks, duplicate refusal, upload validation, hexadecimal/canonical upload identifiers, exact package bytes, reviewer source, release notes and sanitized failures using dummy credentials and simulated responses.
- Reviewer source was rebuilt in a temporary directory without `.git`, reusing the locked build dependencies; its Firefox ZIP matched the release build byte-for-byte.
- No new browser checks were performed for this automation and version-only runtime update. Live Discord compatibility, real message deletion, authenticated AMO submission, signing and delivery of store updates are not established by these automated checks. Submission status must be checked in Actions and Mozilla's Developer Hub.

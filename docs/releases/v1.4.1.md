Wipecord 1.4.1 adds a custom cleanup confirmation with clearer targets, filters and optional message examples. It also includes clearer error guidance, fresher server searches and progress that remains active until all checks finish.

The confirmation opens with Cancel focused and waits for explicit acceptance. Cancel, Escape, close, hiding the panel and Stop prevent a pending cleanup from starting; Stop preserves the stopped outcome. Batch confirmation explains that acceptance also covers the remaining selected targets. A failed dialog cancels safely without falling back to a browser prompt.

Streamer mode starts disabled; enable it before sharing your screen. Message preview starts collapsed on every confirmation and shows at most three shortened examples from the current page, with its eligible count. This is a sample, not the complete deletion list. Discord's server total remains a provisional estimate; private-history totals remain unknown until scanning finishes.

Server searches bypass the browser's HTTP cache. Initially empty results receive bounded, interruptible retries, helping fresh messages become searchable without reloading. Invalid search responses fail safely. Active progress remains indeterminate while searching, paginating or checking again; the final summary alone reports completion. Request errors give clear next steps without exposing private response data. Targets, filters, pacing, cancellation and stopping remain enforced.

## Install or update

Install the attached userscript with your userscript manager, or [install from main](https://raw.githubusercontent.com/rafelolv/Wipecord/main/wipecord.user.js). The main link follows future updates; this release's attachment is a fixed snapshot. No settings migration is required. Chromium requires version 111 or later; Firefox requires 142 or later.

For Chromium, extract its ZIP and load the folder through **Load unpacked** with Developer mode enabled. When updating a local installation, replace its folder and click **Reload** in the extension manager. For Firefox, load the ZIP temporarily through `about:debugging#/runtime/this-firefox`. Confirm version **1.4.1** after updating. See [local installation and updates](https://github.com/rafelolv/Wipecord/blob/main/docs/EXTENSION.md).

Stop active operations before updating, disable other deletion scripts, keep only one Wipecord installation enabled and reload all Discord tabs afterward. These ZIPs are local packages, not store releases or signed Firefox XPIs. This GitHub release does not update the [Firefox store listing](https://addons.mozilla.org/en-US/firefox/addon/wipecord/); store submission, review and signing are separate actions.

## Validation

- Clean `npm ci` and `npm run check` passed lint, 32 mocked unit tests, metadata/license/syntax, matching shared-engine hashes and deterministic packaging.
- Mozilla's local validator reported **zero errors, zero warnings and zero notices**. This does not replace AMO review.
- The Chrome userscript fixture passed 29 interaction checks, native Escape/Enter cancellation, inert confirmation markup, failed-dialog cancellation, keyboard controls, dragging/resizing and five panel/dialog viewport/theme checks. The collapsed desktop dialog was visually reviewed.
- Chrome 154.0.8037.97, Firefox 157.0 and Brave Origin Nightly 1.98.28 (Chromium 154.0.8037.58, Wayland/GPU enabled) passed all seventeen extension scenario groups with temporary profiles and simulated responses.
- Scenarios cover the initial disabled Streamer mode, explicit masking, collapsed preview on successive openings, safe cancellation/stopping, one explicit confirmation for a batch, duplicate installations, origin-wide locking, preserved filters, history pagination, fresh searches without reload, provisional progress, rejected imports and anonymous reports. The bounded-sample unit fixture uses 100 eligible messages and a search estimate of 1,800; unsampled messages are never formatted.

Browser checks were completed on the unchanged runtime immediately before this release preparation. No real messages were deleted. Live Discord DOM/authentication/API, Edge, Brave stable, minimum supported versions, Android, live rate limiting and signed/store installation remain unvalidated. See [validation details](https://github.com/rafelolv/Wipecord/blob/main/docs/EXTENSION-VALIDATION.md).

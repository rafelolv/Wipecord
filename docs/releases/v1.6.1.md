## Install or update

- Install the attached userscript with your userscript manager, or [install from main](https://raw.githubusercontent.com/rafelolv/Wipecord/main/wipecord.user.js). The main link follows future updates; the attachment is a fixed release snapshot. No settings migration is required.
- For Chromium, extract its ZIP and select the folder with **Load unpacked** in Developer mode. To update, replace the existing local folder, click **Reload** in the extension manager and confirm version **1.6.1**. Chromium 111 or later is required.
- For local Firefox testing, load its ZIP through `about:debugging#/runtime/this-firefox`. Firefox 142 or later is required. See [local installation and updates](https://github.com/rafelolv/Wipecord/blob/main/docs/EXTENSION.md).
- Stop active operations before updating, disable other deletion scripts, keep only one Wipecord installation enabled and reload all Discord tabs. Reloading also removes any sidebar shortcut left by an already-running 1.6.0 page.
- These ZIPs are local packages, not store releases or signed Firefox XPIs. This GitHub release does not update the [Firefox store listing](https://addons.mozilla.org/en-US/firefox/addon/wipecord/); submission, review and signing are separate actions.

## Validation

- Clean `npm ci` and `npm run check` passed lint, 32 mocked unit tests, metadata/license/syntax checks, byte-identical packaged engines and deterministic ZIP verification.
- Mozilla's local validator reported **zero errors, zero warnings and zero notices**. Local validation does not replace AMO review.
- The final 1.6.1 userscript passed 32 Chrome interaction checks, native keyboard confirmation behavior, dragging/resizing and five viewport/theme layouts. The synthetic server rail remained untouched. The existing design and text-only hover were visually reviewed during this development cycle.
- Chrome 154.0.8037.97, Firefox 157.0 and Brave Origin Nightly (Chromium 154.0.8037.58, Wayland/GPU enabled) passed all seventeen extension scenario groups on the final runtime immediately before release preparation.
- Scenarios cover startup/reload, header replacement, read-only popup, duplicate prevention, cross-tab exclusion, confirmation/cancellation, preserved filters, history pagination, stopping, search recovery, progress, imports and anonymous reports. The UI changes preserve the shared deletion engine, request pacing and privacy settings.
- All browser checks used temporary profiles and simulated messages/responses. No real messages were deleted. Live Discord DOM/authentication/API, Edge, Brave stable, minimum supported browser versions, Android, live rate limiting and signed/store installation remain unvalidated. See [validation details](https://github.com/rafelolv/Wipecord/blob/main/docs/EXTENSION-VALIDATION.md).
